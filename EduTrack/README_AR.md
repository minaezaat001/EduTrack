# مشروع EduTrack التدريبي (ASP.NET Core MVC & Identity)
## خاص بطلاب Core Academy — إشراف م. مينا عزت

يحتوي هذا المجلد على:
1. **`Models/`**: جميع كلاسات قاعدة البيانات الـ 6 (`ApplicationUser`, `Instructor`, `Course`, `Student`, `Assignment`, `Submission`).
2. **`ViewModels/`**: جميع كلاسات الـ ViewModels الـ 7 الجاهزة للربط مع الفورمات ورفع الصور والملفات.
3. **`Views/`**: جميع شاشات الـ Frontend (`.cshtml`) جاهزة بالكامل بتصميم Bootstrap 5 RTL، وفي أعلى كل ملف شرح واضح للـ Action المطلوب برمجته داخل الـ Controller.
4. **`wwwroot/css/site.css`**: ملف التنسيقات الأساسي، بالإضافة إلى المجلدات الجاهزة لحفظ الصور والملفات المرفوعة:
   - `wwwroot/images/instructors`
   - `wwwroot/images/courses`
   - `wwwroot/uploads/assignments`
   - `wwwroot/uploads/submissions`
